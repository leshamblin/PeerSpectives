PeerSpectives Overview

PeerSpectives is an NC State-branded Google Apps Script web app used to collect peer evaluations for team-based courses. It combines a responsive HTML/CSS/JS front end with server-side Apps Script code that writes to a shared Google Sheet and generates a Google Doc record for each submission.

Repository Structure

  • Code.gs – Main server logic (doGet, review validation, rubric fetch, submission handler).
  • Utilities.gs – Spreadsheet/file helpers (roster lookup, question loader, Drive doc creation).
  • Index.html – Base HTML template served to users.
  • Scripts.html – Front-end JavaScript (state management, slider UI, submission flow).
  • Styles.html – CSS theme for the NC State look and feel.
  • good-slider.md – Notes on reproducing the custom noUiSlider rubric control.

Data Model (Google Sheet)

  • Roster: Columns Name / Email / Team – used to authenticate reviewers.
  • Team Assignments: Reviewer Team → list of teams they must review.
  • Teams: Team name + project video/link.
  • Questions: Rubric definition (name, type, scale max, label, category, hover text).
  • Logs: Append-only submission log (timestamp, reviewer info, answers JSON, doc URL).
  • Config: Simple key/value pairs for course number, support email, etc.

Drive Output

Every submission is recorded in a Google Doc inside the Reviews folder. Set the script property REVIEW_PARENT_FOLDER_ID to store that folder inside a specific Drive directory. Document names follow the pattern <Reviewee Team> (1) so new submissions overwrite the existing doc for each team.

How the App Works

  1. User loads the web app: doGet() injects their NC State email into the template.
  2. Authentication: The client calls getRevieweeChoices to confirm the user is in the roster and fetch their assigned reviewees.
  3. Rubric: The rubric is built dynamically from the Questions sheet via getRubric.
  4. Submission: submitReview validates all answers, generates a Drive Doc, logs the row, and returns the doc URL.
  5. Post-submit UI: Users see a toast with remaining assignments and a link to the shared doc.

Deployment Notes

  • Set required script properties: SPREADSHEET_ID (target Google Sheet) and optionally REVIEW_PARENT_FOLDER_ID.
  • Deploy as a web app with Execute as: Me and Who has access: Anyone within NC State.
  • When editing client files (Index/Scripts/Styles), paste them into the Apps Script editor tabs of the same name.

Resetting a Student's Review Count

The counter shown in the UI is computed from the Logs sheet. Each row corresponds to one submitted review, and column C stores the reviewer email. To reset (or lower) a student's count, delete the rows in Logs that contain their email or clear column C for those rows. The next time the student loads the app, their completed count will reflect the updated log.

Support

Update the Config sheet’s techsupport email value to control the “contact” message shown to students.
